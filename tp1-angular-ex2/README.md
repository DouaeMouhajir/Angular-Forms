# TP N°1 : Angular - Formulaires (Exercice 2 : Reactive Forms)

## Démarrage rapide dans VS Code

1. Décompressez le fichier ZIP et ouvrez le dossier contenant `package.json` dans **VS Code**.
2. Ouvrez le terminal intégré (`Ctrl + ù` ou `Terminal > New Terminal`).
3. Installez les dépendances :
   ```bash
   npm install
   ```
4. Lancez le serveur de développement :
   ```bash
   npm start
   ```
5. Ouvrez votre navigateur sur `http://localhost:4200`.
